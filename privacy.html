Privacy policy

simurg-yukleyici · last updated 26 October 2026

simurg-yukleyici is a private desktop tool used only by the owner of the YouTube channel Simurg (@simurghistory) to upload videos to that channel and read its own analytics. It is not offered to the public.

What the tool accesses

With the channel owner's permission, the tool uses the YouTube Data API and the YouTube Analytics API to upload videos, edit their titles and descriptions, and read view statistics for the Simurg channel. It does not access any other person's account or data.

Where the data stays

The access token Google issues is stored only on the channel owner's own computer. Nothing is sold, shared with third parties, or sent to any server other than Google's.

Revoking access

Access can be removed at any time from Google Account → Third-party connections.

Google and YouTube

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
